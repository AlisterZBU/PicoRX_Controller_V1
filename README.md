# PicoRX_Controller_V1
Cross-platform python+Tkinter script to run headless Jon Dawson's excellent PicoRX 
Connects to PicoRX via USB. Warning/WARNING: Do not connect any local battery to the PicoRX else Pico's diode will cook!
Read the Warning!
Click mouse on the frequency display as follows: top half of a digit will increment the frequency and click
on the bottom half to decrement it.
